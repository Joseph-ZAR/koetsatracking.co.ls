## Publish with GitHub Pages
1. Create a new **Public** GitHub repository named `koetsa-tracking-system`.
2. Download and unzip this package.
3. Open the repository and choose **Add file → Upload files**.
4. Upload all files and folders inside this package (not the outer ZIP).
5. Commit the upload to the `main` branch.
6. Open **Settings → Pages**. Set Source to **Deploy from a branch**, Branch to **main**, Folder to **/(root)**, then Save.
7. Your website address will be `https://YOUR-GITHUB-USERNAME.github.io/koetsa-tracking-system/`.
